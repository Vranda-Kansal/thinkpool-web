## What is Thinkpool?

Thinkpool is a **developer-first community-driven platform**. Find developers who think like you, collaborate on ideas, and build your network.

> Think of it as Tinder × LinkedIn, built specifically for the developer community.

---

## ✨ Features

- **🔍 Developer Discovery** — Go through developer profiles shown in Feed.
- **📨 Send Request** — Either show interest in a developer profile or pass them.
- **🤝 Smart Matching** — Connect only when both sides show interest — no awkward cold follows.
- **👤 Rich Profiles** — Showcase your skills, projects, experience, and what you're looking for by editing your profile.
- **🔐 Secure Auth** — JWT-based authentication with HTTP-only cookie sessions, login and sign up using email and password.
- **📋 Requests** — See the list of developers who have shown interest in your profile, and choose to connect or not.
- **🔗 Connections** — List of all developers in your network, with the ability to chat with them.
- **⚡ Real-time Ready** — Real Time Chat, Online status, presistent messages history.
- **📱 Responsive UI** — Clean, mobile-friendly interface built with Tailwind CSS.
